# Первая часть задания C# для практики
Программа ищет 5 ближайших водителей к заказу на карте 1000x1000
## Структура
- TaskCore - алгоритмы поиска и модели
- TaskTests - тесты NUnit
- TaskBenchmarks - замеры скорости Benchmark
## Реализованные алгоритмы
1. LinearAlg - перебирает всех водителей, а потом сортирует по расстоянию
2. PriorityAlg - создает список из 5 лучших кандидатов и обновляет его
3. RadiusAlg - расширяет радиус поиска пока не найдёт 5 водителей
## Тесты
Все разработанные алгоритмы покрыты тестами с помощью NUnit
